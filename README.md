# RustInfo releases

Downloads for **RustInfo**, a free Windows desktop companion for Rust built on the official Rust+ protocol. Keep your team map, smart devices, deaths and raid tools on a second screen while you play.

## Download

**[⬇ RustInfo-win-Setup.exe (latest)](https://github.com/Snickers-Bar74/RustInfo-Releases/releases/latest/download/RustInfo-win-Setup.exe)**

Windows 10 (1809 or newer) or Windows 11, 64-bit. Free. Everything it needs is included in the installer.

Windows may show **"Windows protected your PC"** because the installer isn't code-signed yet. Click **More info → Run anyway**.

Each release lists the SHA-256 checksum of every file.

## Not a cheat

RustInfo never touches the game: no memory reading, no injected code, no macros or fake input. It talks only to Rust+, the same service the official phone app uses.

## Getting started

1. Run the installer.
2. In RustInfo, open **Settings → Pairing → Set up** and sign in with Steam.
3. Join your server in Rust, press **Esc → Rust+** and pair it.
